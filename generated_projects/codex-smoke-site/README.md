# codex-smoke-site

## What this is
codex-smoke-site is a portfolio for Potential clients. ZAIRE will ship it as a frontend-first experience with no authentication, no database, and no payments in v1.

## Stack
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Static app shell
- Client fetch orchestration
- No persistent database required
- Anonymous access or lightweight session state
- No payment rails required

## Pages
- Landing / value proposition
- Authenticated workspace
- Project detail / execution view
